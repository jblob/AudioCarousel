# My Music Player

## General Description
This project is just another mp3/mp4 player with some features I did not find elsewhere (see "Features" below). It was mainly a project to learn a bit how to use PyQT/PySide.

---

## Requirements
To run this project, you will need the following software components. No specific hardware or firmware is required.

*   **Python:** Python 3.x
*   **Python Libraries:** 
    *   `PyQT5` (porting to PySide6 is planned)
    *   `mutagen` (for reading MP3/MP4 Tags)

---

## Installation Instructions
Follow these steps to set up the environment and run the application locally:

1.  **Clone the repository:**
    ```bash
    git clone <your-repository-url>
    cd <repository-folder>
    ```

2.  **Install the required dependencies:**
    Make sure you have `pip` installed, then run:
    ```bash
    pip install PyQT5 mutagen`
    ```

3.  **Run the script:**
    ```bash
    python MusicPlayerJB.py
    ```
